# PROTOCOLLO ANALISI TECNICA E POSIZIONAMENTO

**SEZIONE 1: IDENTIFICAZIONE PROIEZIONE (AP vs PA)**
1. **Verifica Input Utente:** Se l'utente specifica "AP" o "PA", accetta come verità assoluta.
2. **Analisi Scapole (Fase Immagine Intera):**
   - SE i bordi mediali delle scapole sono visibili all'interno dei campi polmonari -> **DIAGNOSI: Proiezione AP**.
   - SE le scapole sono ruotate esternamente e fuori dai campi -> **DIAGNOSI: Proiezione PA**.
3. **Analisi Clavicole:**
   - In AP: Le clavicole appaiono alte e con decorso orizzontale.
   - In PA: Le clavicole hanno un decorso obliquo a "V" verso il basso.

**SEZIONE 2: IMPLICAZIONI CLINICHE**
- SE Proiezione == AP: L'ombra cardiaca risulterà ingrandita (falsa cardiomegalia). Non segnalare cardiomegalia se non corretta per proiezione.
