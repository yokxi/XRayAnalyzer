# PROTOCOLLO DIAGNOSI DIFFERENZIALE: SCOMPENSO VS POLMONITE
# Fonti: RadioGraphics, Radiology Assistant

**SEZIONE 1: SEGNI SPECIFICI DI SCOMPENSO CARDIACO (CHF)**
1. **Linee B di Kerley:**
   - **Aspetto:** Linee orizzontali corte (1-2 cm), perpendicolari alla pleura, visibili alle basi polmonari (angoli costofrenici).
   - **Significato:** Edema interstiziale (setta interlobulari ispessiti da liquido). Altamente specifico per insufficienza cardiaca o renale.
   - **Regola:** SE (Linee B presenti AND Cardiomegalia) -> Probabile Edema, NON Polmonite.

2. **Ridistribuzione Vascolare (Cefalizzazione):**
   - **Aspetto:** I vasi dei lobi superiori diventano più larghi di quelli dei lobi inferiori (in posizione eretta).
   - **Significato:** Ipertensione venosa polmonare (Stadio 1 CHF).

3. **Versamento Pleurico:**
   - **Scompenso:** Tipicamente BILATERALE o isolato a DESTRA.
   - **Polmonite/Infezione:** Spesso UNILATERALE e asimmetrico.

4. **Peribronchial Cuffing:**
   - **Aspetto:** Ispessimento "a ciambella" delle pareti bronchiali viste di fronte.
   - **Significato:** Edema della parete bronchiale.

**SEZIONE 2: ALGORITMO DECISIONALE**
- **Scenario A:** Opacità bilaterali "a ali di farfalla" + Cuore Grande + Linee B -> **DIAGNOSI: Edema Polmonare**.
- **Scenario B:** Opacità focale/asimmetrica + Broncogramma aereo + Cuore Normale -> **DIAGNOSI: Polmonite**.
